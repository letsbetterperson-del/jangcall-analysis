# AI 사용 기록 (공모전 규정: 사용 AI 서비스·활용 범위·주요 프롬프트 명시)

## 1. 분석 안에서 쓴 기계학습
| 기법 | 도구 | 쓰인 곳 | 결정에 쓰이는 방식 |
|---|---|---|---|
| 그래디언트 부스팅 회귀 | scikit-learn 1.7.2 `HistGradientBoostingRegressor` | `05_forecast.py` 다음 날 07~10시·14~18시 호출 수 예측 | 수요가 요일·공휴일로 오차 7~8% 안에 예측되는지 확인 → 근무표를 고정 재설계해도 되는 근거 |
| (통계·운영연구, AI 아님) | numpy·pandas | Kaplan-Meier·누적발생(`02`), 대기열 역산(`03`), 추적형 시뮬레이션·탐욕 탐색(`04`) | 핵심 결과 |

## 2. 생성형 AI
- 서비스: Anthropic Claude — Claude Code(명령줄 도구), 모델 Claude Opus 계열, 2026년 10월 사용
- 활용 범위
  1. 공공데이터포털 파일데이터 목록·메타데이터 확인과 내려받기 경로 정리
  2. 분석 코드 초안 작성·오류 수정(00~09 스크립트), 그림 코드
  3. 시뮬레이터 보정 방식 비교(선착순/예약 우선/무작위 혼합, 시간대 계수) 실험 코드
  4. 보고서 문장 초안·교정
- 쓰지 않은 것: 데이터 생성·보완 없음. 개인정보·비공개 자료 입력 없음(입력한 것은 공개 파일의 열 이름·집계 결과뿐). 보고서의 모든 수치는 공개 코드가 원자료에서 다시 계산한 `out/summary.json` 값이며, `09_numcheck.py`로 원고 숫자를 전부 대조함
- 검증: 공식 '시간대별 대기시간'을 같은 정의로 재현(일×시 8,714칸 상관 0.993), 시뮬레이터는 학습에 쓰지 않은 평일 122일로 검증

## 3. 주요 프롬프트(요지, 원문은 한국어)
1. "공공데이터포털에서 로그인 없이 받을 수 있는 서울 장애인콜택시 호출 단위 자료를 찾아 열 구성과 기간을 확인하고 내려받는 스크립트를 만들어줘."
2. "탑승내역에서 즉시 호출과 예약 호출을 나누고, 취소를 중도절단으로 둔 Kaplan-Meier로 '호출 후 60분 안에 탈 확률'을 시간대·자치구·행정동별로 계산해줘. 탑승 완료 건만 쓴 평균과 나란히 놓아줘."
3. "공단이 공개한 시간대별 대기시간을 같은 정의로 재현해서 우리 계산이 맞는지 상관과 평균 오차로 확인해줘."
4. "1분 단위로 운행 중 차량(배차~하차)과 배차 대기 호출을 세고, 대기 호출이 10건 이상 쌓인 시각의 운행 차량을 근무 차량으로 보는 평일 공급 곡선을 만들어줘."
5. "그날의 실제 호출을 다시 흘리는 시뮬레이터를 만들어줘. 포기한 호출은 실제 포기 시각, 탄 호출은 인내 분포에서 조건부로 뽑고, 학습일로 시간대별 유효 공급 계수를 보정한 뒤 검증일에서 시간대별 오차를 보고해줘."
6. "단시간 운전원 55명×5시간을 출퇴근 집중안, 06~22시 균등안, 30분 간격 시작 시각 탐욕 탐색안으로 나눠 검증일 기준 60분 내 탑승 비율과 포기율을 비교해줘."
7. "요일·공휴일·기온·강수·1주 전 값으로 다음 날 시간대 호출 수를 예측하는 모델을 시간 순 분할로 평가하고, 1주 전 값 단순 예측과 비교해줘."
