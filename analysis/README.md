# 장애인콜택시 포기 포함 대기 분석·운전원 시간대 배치 시뮬레이션 — 재현 코드

숲과나눔·한겨레 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 분석보고서(이완)의 전체 재현 코드.
원자료는 모두 로그인·API 키 없이 받는다. 숫자는 `out/summary.json`에서만 보고서로 옮긴다.

## 실행 순서 (Python 3.10, `pip install -r requirements.txt`)
| 순서 | 스크립트 | 하는 일 | 주요 산출 |
|---|---|---|---|
| 0 | `00_download.py` | 공공데이터포털 파일 6종·행정동 경계·Open-Meteo 기상 내려받기 → `../data/raw/` | 원자료 |
| 1 | `01_prep.py` | 정제(즉시/예약 구분, 대기 시계, 포기 정의) | `out/01_*.csv` |
| 2 | `02_survival.py` | 공식 집계 재현 검증, Kaplan-Meier·누적발생, 시간대·자치구·행정동 | `out/02_*.csv` |
| 3 | `03_supply.py` | 1분 격자 운행 중 차량·배차 대기 호출 → 근무 차량 역산 | `out/03_*.csv/parquet` |
| 4 | `04_sim.py` | 추적형 시뮬레이터: η 보정(학습일)·검증(검증일)·배치안 비교·탐욕 탐색·투입량 곡선 | `out/04_*.csv/json` |
| 4b | `04b_equity.py` | 형평 목표(가장 나쁜 시간대) 배치안 | `out/04_eq_schedule.json` |
| 5 | `05_forecast.py` | 다음 날 시간대 호출 수 예측(그래디언트 부스팅) | `out/05_*.csv` |
| 6 | `06_carbon.py` | 운행거리·빈 차 접근·유종 기반 CO₂ 추정(가정값 범위) | `out/summary.json` |
| 7 | `07_figures.py` | 보고서 그림 | `fig/*.png` |
| 8 | `08_garage.py` | 자치구 차고지·접근시간·60분 내 탑승 확률 상관 | `out/08_garage_gu.csv` |
| 9 | `09_numcheck.py` | 보고서 원고 숫자 ↔ 산출물 대조 | `out/수치대조.csv` |

## 공단 내부 자료로 바꿔 넣는 곳
- `04_sim.py`의 기준 공급 `N`(10분 슬롯 근무 차량 수)은 공개 자료에서 역산한 값이다. 공단 운전원 근무표가 있으면 `build_days()`의 `N`을 그것으로 바꾸면 η 보정 없이 바로 돈다.
- 배차 규칙(`simulate()`)의 예약 우선·선착순 비율 `Q_OLD`는 공개 자료로 고른 대리값이다.
